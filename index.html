HP Debloat

Strip the OEM stack off a new HP PC. Wolf Security, Sure Click, Support Assistant, Insights, JumpStart, and the McAfee trial — gone. Drivers, audio, hotkeys, and OneDrive stay.

irm https://raw.githubusercontent.com/accentdavid/hp-debloat/main/hp-debloat.ps1 | iex

Run in an elevated PowerShell or Windows Terminal. NinjaOne can run the same script as SYSTEM with no prompts. Log lands in C:\\ProgramData\\AccentLogic\\HP-Debloat.log.

Removed

  • HP Wolf Security + Sure Click / Run / Sense / Recover (correct order)
  • HP Support Assistant, myHP, JumpStart, Documentation
  • Connection Optimizer, Notifications, Insights / Touchpoint
  • Omen Gaming Hub / Command Center (consumer images)
  • McAfee LiveSafe, WebAdvisor, Norton trial, ExpressVPN stub
  • Orphan HP scheduled tasks and Insights services

Kept

  • OneDrive
  • HP / Realtek audio control
  • Hotkey / Fn-key services
  • Chipset, GPU, touchpad drivers
  • HP Smart — only if an HP printer is present
  • Anything not on the explicit remove list

Optional switches

irm https://raw.githubusercontent.com/accentdavid/hp-debloat/main/hp-debloat.ps1 -OutFile $env:TEMP\\hp-debloat.ps1
& $env:TEMP\\hp-debloat.ps1 -KeepSupportAssistant
& $env:TEMP\\hp-debloat.ps1 -KeepOmen
& $env:TEMP\\hp-debloat.ps1 -Force          # non-HP hardware
& $env:TEMP\\hp-debloat.ps1 -WhatIf         # log only

Refuses non-HP machines unless you pass -Force. Detection tag: C:\\ProgramData\\AccentLogic\\HP-Debloat.tag.
