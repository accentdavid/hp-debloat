HP Debloat

One elevated command strips consumer HP junk, trial AV, and the Wolf / Sure* stack from a new HP PC. Audio, hotkeys, OneDrive, and hardware diagnostics stay.

Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/accentdavid/hp-debloat/main/hp-debloat.ps1 | iex

Removes

  • myHP, JumpStarts, QuickDrop, WorkWell, EasyClean, Welcome
  • HP Support Assistant, Notifications, Documentation
  • Wolf Security + Sure Click / Sense / Run / Recover
  • Connection Optimizer, Insights, Touchpoint, Poly Lens
  • McAfee LiveSafe, WebAdvisor, Security Scan Plus

Keeps

  • OneDrive
  • HP Audio Control / Realtek
  • Fn-key / hotkey UWP services
  • Chipset, GPU, NIC, touchpad drivers
  • HP PC Hardware Diagnostics

Refuses non-HP hardware unless you add -Force. Use -WhatIf for a dry run. Log: C:\ProgramData\AccentLogic\HP-Debloat.log. If Wolf comes back after reboot, disable HP Sure Run in BIOS and re-run. Microsoft Store junk is a separate pass — Ninja script Remove Microsoft Bloatware (id 88). Source: github.com/accentdavid/hp-debloat
